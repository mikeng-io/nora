# T3 Code (session host)

T3 hosts the operator-facing session and its delegated workers, across
providers.

- **Finding related work.** The project's thread search and list are the
  session store `nora-dispatch` step 2 means; read a thread's checkout, head and
  latest handoff, never infer ownership from its title.
- **Delegated workers.** `delegate_task` with `isolation: worktree` starts the
  worker's worktree from the orchestrator's local commit. Verify it against the
  assigned base and preserve required unpublished commits; do not restart
  dependent work on master or create a second worktree. A reviewer selects the
  exact head under review.
- **Status mid-turn.** Text written before a tool call may reach the operator
  only as a one-line summary; send an item-boundary status with `send_to_user`.

# Context selector host probe — 2026-10-07

Verified on norty over SSH. Ryzen 7 PRO 6850U (8 cores / 16 threads), Radeon 680M (PCI 1002:1681), Linux 7.0.0-34, approximately 27.7 GiB usable system RAM. The GPU has 3 GiB reserved VRAM and approximately 13.8 GiB GTT; these are not additive dedicated model capacity. Ollama 0.35.0 already installed, using HSA_OVERRIDE_GFX_VERSION=10.3.0 and OLLAMA_VULKAN=1. No host configuration, driver, Nora source, or live Nora config was changed.

## Method

Eight generated, labelled context-selection situations: English/Cantonese document requests, English/Cantonese personal recall, an ongoing computer task, delegated work, a greeting, and an older discussion requiring the full transcript. Five choice questions per situation: four optional blocks plus transcript depth (8/20/40). The optional candidates are peer_history, documents, computer, subagents. State includes a clock, current message, synthetic tagger, Culture, Standing, available block definitions, and content/row cues. This is a classifier smoke probe, not Nora's snapshot eval or evidence of end-to-end benefit. Expectations were set in the script before calls.

All 40 choices were returned by each tested arm; no inference error was observed. Required-block misses are worse than unnecessary inclusions. Exact-match counts below weight both equally and must not be interpreted as deployment accuracy. No repeated draws, independent holdout, threshold calibration, or production input distribution was tested.

The GPU service runs under the existing ollama account. Journal readback binds ROCm0 to PCI e5:00.0, the Radeon 680M. It records 25/25 layers offloaded for Tev1 0.8B and 33/33 for 4B. Resident sizes were approximately 0.894 GB and 4.669 GB respectively. The separate CPU server reported size_vram=0. The 0.8B GPU median was approximately 2.85 times faster than CPU.

Tev1 4B's first one-question warmup after loading took 13.06 s; its per-case medians exclude this load. The initial isolated 0.8B smoke call took 4.20 s including loading. Keep a deployment resident if latency is material.

Both Tev1 sizes chose 8 rows for the old-thread case, despite metadata locating needed facts at rows 2, 12, and 29 of 40. Tev1 4B also unnecessarily chose 20 for a greeting. Transcript sufficiency is not proven by optional-block success. The CPU and GPU 0.8B outputs differed on one optional-block inclusion, so backend agreement is not perfect.

Strands uses installed torch 2.14.1+cu130; torch reports no available CUDA and no HIP runtime. Inference uses CPU and reference causal convolution / gated-delta kernels. Its iGPU path was not tested. Its last two measurements overlapped the secondary Tev1 bundle probe and are not clean isolated latency samples; the earlier request durations were approximately 8.4–10.0 s. Laya is the cached English ModernBERT checkpoint, not multilingual; it dropped zero state tokens in these requests. Its installed loader warned about an unrelated invalid choice:11+ calibration value. No claim is made about the multilingual or specialized Laya checkpoints.

## Secondary bundle probe

One question selects one of six optional-context bundles, instead of four block decisions plus depth. Tev1 4B: 6/8 matched the narrow expected bundle; warm median excluding first load was 1.347 s. It omitted English personal recall and selected full fallback for the old-thread case. Thus the reduction in latency came with a required-context miss. This secondary probe overlapped the tail of the Strands CPU probe; timing is exploratory. Bundle choices cover only single-domain situations and do not establish mixed-domain adequacy.

## Recommendation

Keep Tev1 4B as the measured candidate for a subsequent optional-block exposure trial. Do not integrate Tev1 0.8B, Laya English, or the single-choice bundle shortcut based on this probe. Keep transcript depth and quote preservation deterministic initially; full context remains the failure/uncertainty fallback. Compare against a conservative deterministic selector, then use Nora's existing anchored snapshot evaluation before any behavioral change ships. A four-second selector is acceptable only if total reply latency, quality and uncached cost improve enough to pay for it.

JEV was not called: no JEV/TYPESAFE/TOGETHER credential name was present in the deployment .env. Strands-plus-pre-ranker, multilingual Laya, and a small general LLM remain unmeasured. A pre-ranker must first prove shortlist recall and account for its own cost. ROCm iGPU operation for Ollama is verified; ROCm PyTorch support for this Strands checkpoint is not.

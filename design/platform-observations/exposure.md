# Exposure and attention

## Transcript and ongoing context

Engagement interleaves supported source events with ordinary speech. Replies,
edits, reactions and shares annotate their targets; poll, room, membership,
pin and thread changes appear as typed platform events, never fabricated human
utterances. A native service message and its structured observation render once.

The recent transcript is a presentation window, not retention. A new change on
an old target can enter with a scoped handle and enough target context to be
understood without restoring the whole conversation. Relevant ongoing matters
retain fresh source state through the existing Standing presentation.

Cognition receives room-bound observation agenda items, grounded source rows
and explicitly declared Standing input. A co-delivered utterance appears beside
its observation while delivered-message and affected-target identity remain
distinct. Every prompt block still comes through declared context assembly;
there is no separate social-metadata block or hidden renderer query.

Source events describe changes; Standing describes current state. Culture and
Notebook provide the longer interpreted account. A poll close, reaction or
membership change never automatically declares agreement, attendance, intent
or an arrangement settled.

## Task reads

Existing transcript, Record, graph, roster and saved-media tools retain their
own authority. Typed Record queries add source-object kind, handle, history and
as-of reads while preserving the original message-search behavior and disabled
reader boundaries. Current-room typed queries cannot silently become an
all-room result.

Poll discovery and detail expose definitions, supported tallies, voter coverage
and current state. Room-state reads expose supported title, topic, membership,
role, permission, pin and thread state with their actual source grain. Existing
conversation reads are not repurposed as metadata tools by their names.

Cognition's tool catalogue, audit and roster binding must explicitly admit each
read and bind a multi-room wake's actual item room. Registry presence alone
does not expose a tool. Saved artifact reads do not become blanket live-fetch
or feed-crawling authority, and no universal query or per-platform cognition
tool is introduced.

## Stimulus ownership

One observation stimulus family covers non-message poll and room evidence;
there is no stimulus kind per platform. A message delivered with a structured
observation owns one durable source obligation carrying both references and
the utterance snapshot. The ordinary duplicate message stimulus is suppressed
only after that ownership is durable.

Observation-only and silent message-sibling paths retain their own obligations.
Malformed sidecars do not consume the utterance's work, and handling a message
cannot consume unseen poll or room evidence. Distinct later transitions remain
distinct evidence even when an agenda batches them.

Grounding, rendering, admitted-proposal coverage, retry, parking and historical
replay share the same observation lifecycle. Useful changes accumulate under
existing coalescing and wake rules; a callback does not imply a model call.
New evidence can become relevant without a pre-existing Notebook link.

Typing produces no Record, stimulus, context or model work. Budget overflow,
unavailable reads and unresolved targets remain explicit with bounded detail
paths. A source observation missing from a turn is investigated at capture,
projection, selection or rendering rather than explained away as irrelevant.

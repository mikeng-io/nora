## Contracts this proposal changes

The Discord listener design's “No separate collector process” no longer meets continuous receipt/reaction. Amend its lifecycle, not Discord's upstream history semantics. The Discord music control design's app-client ownership moves to discord-bridge; existing controllers remain external.

WA/IG transport contracts currently divide raw bridge events from app normalization and SSE replay. Amend them so bridge-side parsers produce the shared normalized envelope once; app reconstructs the typed value without reinterpreting raw text. Preserve Instagram social/resource APIs and summons routing (summons becomes a durable event kind dispatched to its existing app path).

The turn-record design is provenance, not a restart scheduler. Extend it by reference to queue work/action identity; do not replace it or widen the successful-lookup log into a workflow engine. Context assembly remains the only prompt builder; recovery introduces no model occasion.

Observability currently says deterministic roots are never exported. The operator explicitly requests individual queue traces: [operations](04-operations.md) proposes a narrow amendment while keeping ordinary plumbing dropped and model provenance intact. Existing historical statements remain truthful; maintained current contracts must point to this amendment when implemented.

# The model's surface

The model's surface is what a pass shows the model and lets it call. It is
derived from the graph: the instruction states what each kind means, the
context is retrieval's prefetch, and the tools are retrieval plus one write
verb per basis the model may propose.

## Instruction

- **Prelude**: Nora's purpose in this pass.
- **Objective**: the stages the pass runs and the few rules code cannot
  enforce.
- **Guidance**: each offered tool's own short guidance, injected only when the
  tool is offered, so the instruction follows the actual surface.
- **Context**: declared blocks assembled by context assembly; every block
  carries what its judgement turns on — time, who, and what would close it.

## Tools

| tool | stage | writes |
|---|---|---|
| read tools: search, rows, neighbourhoods, transcripts, media, permitted outside reads | orient, decide | nothing |
| **propose** | orient, study's learn and grade | entities, claims, edges (inferred); lessons are claims about Nora's practice; a grade is a claim about the graded row, citing its later evidence |
| **commit** | decide | intentions (committed): open, revise, drop |
| **send_reply** | act | nothing; delivery is recorded by observe |

## Surface per pass

| pass | reads | propose | commit | send_reply |
|---|---|---|---|---|
| called, ambient | yes | no | yes | yes |
| proactive | yes | no | no | yes |
| subconscious | yes | yes | yes | no |
| subconscious, over history | yes | yes, never lessons | no | no |
| review (the judge) | the graded rows and their later evidence | grades only | no | no |

Understanding from a conversation is written once, by a subconscious pass
reading the recorded turn; conscious passes only read it. A proactive pass
cannot commit, so a delivery cannot schedule another delivery.

## Admission

Every write passes code before its table:

- its citations resolve to rows the pass was shown or read, and every chain
  ends in observed or computed rows;
- kind, edge type, endpoints and lifecycle transition are legal;
- reasoning and confidence are representable, and nothing inferred is promoted
  to told;
- its scope narrows but never widens beyond its evidence;
- credential and doctrine protections run before storage, and the content
  checks too when their operating mode enables them ([boundaries](boundaries.md));
- a lesson also passes the independent doctrine check, the citation floor and
  the unit's lesson budget;
- provenance — pass, model, instruction, trace — is stamped by code.

A refusal returns a typed reason so the model can repair the proposal. Valid
siblings are admitted independently. A store failure whose commit state is
uncertain is unavailable, never proof that nothing was written.

## Reasoning and authority

- Told, deduced, induced and abduced are different promises; a routine or
  frequency rests on an aggregate, and an abduced value leaves as a question.
- Third-party memory can suggest what to read; it is never evidence.
- Nora's own words ground only that she said them.

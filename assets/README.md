# Nora visual assets

Generated from `visual-assets.json` by `uv run python scripts/visual_assets.py report`.

All tracked repository images and newly declared source artwork are listed, including the portal's art and icons, the README's images and retained screenshots. Her art's masters are in the private nora-assets repository; a copy names its source as `nora-assets:<path>@<commit>`. Build-generated Next images are derived at build time and are not tracked.

Run `check` to verify coverage, source existence, byte fingerprints and the runtime handle; `sync` to rebuild the portal's icons. These commands do not generate new artwork, ingest media, publish profiles or deploy.

Her art here is all rights reserved (LICENSE); MIT covers the rest of the repository.

## Verification boundaries


Status `active` means the file is the current repository input/output; it does not mean deployment or browser acceptance. Per-file visual review remains pending wherever stated below. Consumers distinguish imports, renderer use, processor inputs and documentation references. An app copy never inherits the site's consumers merely because its basename matches.

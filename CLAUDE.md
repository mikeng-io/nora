# CLAUDE.md

This repo's agent guidance lives in **`AGENTS.md`** — read that file, not this
one. It applies to any agent working in this repo, not just Claude Code; this
file exists only so Claude Code, which specifically looks for `CLAUDE.md`, finds
the same rules instead of a second, drifting copy.

`AGENTS.md` is the entry point because it is the cross-tool convention
([agents.md](https://agents.md)); `CLAUDE.md` is vendor-specific. See
`docs/adr/0010-agents-md-is-the-entry-point.md` for the decision and what it
cost.

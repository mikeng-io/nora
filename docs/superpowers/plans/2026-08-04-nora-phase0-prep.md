# Nora Architecture Refactor — Phase 0 (Prep) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every declared quality gate actually runnable, add the two regression guards the refactor depends on, and decouple the test suite from the config *format* — all against the current code, with all 453 tests staying green.

**Architecture:** Phase 0 changes no production behaviour. It is pure prep: dependency/tooling correctness, two new tests that guard things nothing currently guards, and a set of test-side seams so Phase 1's config rewrite touches one helper per file instead of ten files. Nothing in `nora/` changes except removing dead `# noqa` markers.

**Tech Stack:** Python 3.12, uv, pytest (+asyncio/aiohttp), ruff, mypy, import-linter, aiohttp, Docker.

**Spec:** `docs/superpowers/specs/2026-08-04-nora-architecture-design.md` (revision 2), Phase 0 row in §8.

## Global Constraints

- Dependencies are added with **`uv add`**, never raw pip. `pyproject.toml` + `uv.lock` are the source of truth.
- Container builds require **`docker build --network=host`** — BuildKit's default bridge cannot resolve `deb.debian.org` on this host (systemd-resolved stub `127.0.0.53`).
- The **signal-cli daemon is neutral and shared — never touched.** Nora reads from it; nothing writes to it.
- Honcho health uses **`GET /health`**, never `GET /v3/workspaces` (POST-only → 405 → forever `health: starting`).
- Metric names are **append-only**. `/health` JSON is **additive only** — `deploy/watchdog.sh` parses `body['sse']['last_event_age_seconds']`.
- `pytest` runs with `addopts = "-m 'not network'"`; network-marked tests are excluded by default.
- Python floor stays `>=3.11` in `pyproject.toml` (the deployed interpreter is 3.12).
- **Phase 0 changes no production behaviour.** All 453 tests must pass at every commit.

```python
import ast


def _imported_modules(path: Path) -> set[str]:
    """Top-level module names this file imports, via AST — not substring matching.

    Ignores relative imports (level > 0): those are intra-package and can never
    reach a third-party dependency.
    """
    tree = ast.parse(path.read_text(encoding="utf-8"))
    modules: set[str] = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            modules.update(alias.name.split(".")[0] for alias in node.names)
        elif isinstance(node, ast.ImportFrom) and node.level == 0 and node.module:
            modules.add(node.module.split(".")[0])
    return modules


# Allowlisted by PACKAGE, not by file path, so moving a module within agent/ or
# splitting agent/tools.py into a package does not require editing this test.
STRANDS_ALLOWED_PACKAGES = {"agent"}


def test_strands_import_boundary():
    """Only nora/agent/** may import strands."""
    offenders = []
    for path in _python_files():
        if "strands" not in _imported_modules(path):
            continue
        package = path.relative_to(PKG).parts[0]
        if package not in STRANDS_ALLOWED_PACKAGES:
            offenders.append(str(path.relative_to(ROOT)))
    assert not offenders, f"strands imported outside the agent boundary: {offenders}"
```

```python
"""Test-side construction seams for the config tree.

Phase 1 replaces frozen dataclasses with pydantic-settings. Every direct use of
`dataclasses.replace` or a `nora.config` constructor in the suite is a site that
would break; concentrating them here means phase 1 edits this file, not ten
others. Nothing outside this module may construct or copy a config object.
"""

from __future__ import annotations

import dataclasses
from typing import Any

from nora.config import (
    LimitsConfig,
    LLMConfig,
    LLMTierConfig,
    LoggingConfig,
    TracingConfig,
)


def _with(obj: Any, path: str, value: Any) -> Any:
    head, _, rest = path.partition(".")
    if rest:
        value = _with(getattr(obj, head), rest, value)
    return dataclasses.replace(obj, **{head: value})


def override_config(base: Any, changes: dict[str, Any]) -> Any:
    """Return a copy of `base` with dotted-path fields replaced.

        override_config(cfg, {"buffer.db_path": p, "trigger.min_interval_seconds": 0})

    Format-agnostic by contract: when the config tree becomes pydantic, only
    `_with` changes (to `model_copy(update=...)`), and no caller moves.
    """
    for path, value in changes.items():
        base = _with(base, path, value)
    return base


def make_llm_tier(**kw: Any) -> LLMTierConfig:
    return LLMTierConfig(**{"model": "deepseek-v4-flash", "max_tokens": 400,
                            "temperature": 0.7, **kw})


def make_limits(**kw: Any) -> LimitsConfig:
    return LimitsConfig(**{"turns": 4, "total_tokens": 24000, **kw})


def make_llm_config(**kw: Any) -> LLMConfig:
    defaults: dict[str, Any] = {
        "base_url": "http://localhost:20128/v1",
        "api_key_env": "OMNIROUTE_API_KEY",
        "default": make_llm_tier(),
        "deep": make_llm_tier(model="deepseek-v4-pro", max_tokens=1200, temperature=0.5),
        "limits": make_limits(),
    }
    return LLMConfig(**{**defaults, **kw})


def make_logging_config(**kw: Any) -> LoggingConfig:
    return LoggingConfig(**{"level": "INFO", "path": "nora.log", "format": "json", **kw})


def make_tracing_config(**kw: Any) -> TracingConfig:
    return TracingConfig(**{"enabled": False, "exporter": "file", "endpoint": "", **kw})
```

def _load_eval_config(loader=load_nora_config, candidates=None):
    """`config.yaml` (gitignored, per-deployment) is preferred; `config.example.yaml`
    (committed) is the fallback for a local `config.yaml` predating the schema.

    `loader` and `candidates` are injectable so phase 1's format change is a

    last_error: ConfigError | None = None
    for candidate in candidates:
        try:
            return loader(candidate)
        except ConfigError as exc:
            last_error = exc
    raise last_error
